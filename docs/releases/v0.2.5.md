# BlendUp v0.2.5

- Corrige le démarrage de l’outil de mise à jour Windows lorsque le dossier d’installation enregistré par NSIS est entre guillemets. L’erreur « Lecteur introuvable : \"C » disparaît et l’installation existante est détectée.
- Les chemins collés entre guillemets dans l’assistant ou transmis en mode automatisé sont aussi acceptés. Une entrée de registre invalide ou inaccessible ne bloque plus la recherche des autres installations.
- Ajoute un test sous Windows PowerShell 5.1 pour les chemins cités, les espaces, les entrées absentes ou invalides. Ce test est exécuté avant la construction Windows dans GitHub Actions.

Utilise `BlendUp_0.2.5_x64-update.exe` pour remplacer l’outil 0.2.4 qui échouait avant le début de l’installation. Cette version contient les fonctionnalités de mise à jour et les correctifs Blender de la version 0.2.4.
