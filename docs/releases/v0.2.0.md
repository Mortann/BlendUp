# BlendUp v0.2.0

BlendUp peut maintenant gérer une bibliothèque 3D indépendante de Godot ou Unity. Cette version ajoute les showcases par dossier, l'accès aux assets depuis Blender et Godot, et un travail plus direct avec les variantes.

## Bibliothèque et navigation

- Projets 3D autonomes, en plus des projets associés à Godot et Unity.
- Dossiers repliables, noms personnalisables pour les emplacements du projet, navigation avec les boutons précédent/suivant de la souris.
- Raccourcis clavier, dont F2 pour renommer et Ctrl+D pour dupliquer, indiqués dans les menus.
- Proposition de renommage après duplication et accès aux fichiers locaux depuis les assets et les dossiers.
- Notifications temporaires en bas à gauche, barre de filtres compacte et pages Problèmes/Paramètres plus lisibles.
- « Voir l'asset » retrouve son dossier, sélectionne l'asset et ouvre ses détails.

## Blender et qualité UV

- Indicateur de chargement à l'ouverture d'un asset, remise au premier plan de Blender sous Windows et prise en charge du lancement via Steam.
- Création d'assets sans console visible, avec une option pour les ouvrir automatiquement.
- Options pour appliquer les transformations et effectuer un unwrap Angle Based à chaque enregistrement.
- Vérification UV, score par version et seuil configurable pour bloquer les exports insuffisants. Les coutures font l'objet d'un diagnostic de cohérence.
- Possibilité d'ignorer la vérification UV pour un asset, ses variantes et ses LOD.
- Les sauvegardes de récupération `.blend1`, `.blend2`, etc. ne sont plus considérées comme des assets supplémentaires.
- Correction de l'installation de l'extension dans les versions récentes de Blender.

## Showcases et panneaux d'assets

- Activation d'un showcase par dossier : les assets du dossier et de ses sous-dossiers sont disposés sur un sol pour comparer l'ensemble.
- Génération de scènes Blender et Godot, accessibles depuis un élément distinct dans la bibliothèque.
- Panneaux d'assets pour le projet associé dans Blender et Godot, avec placement des assets. Blender privilégie les instances liées.

## Variantes et aperçus

- Sélecteur de version directement dans l'aperçu de la fiche d'asset ; le choix est mémorisé.
- Aperçu, fichiers, ouverture dans Blender, état d'export et qualité UV suivent la version sélectionnée.
- Variantes et LOD prévisualisables aussi dans les projets 3D autonomes.
- Dans Godot, les nouveaux placements utilisent une instance BlendUp dont la variante peut être choisie avant ou après le placement, depuis l'inspecteur, avec annuler/rétablir.
- Changer de variante conserve la transformation et les enfants de l'instance ; plusieurs instances peuvent utiliser des variantes différentes.
- Un export global poursuit les variantes valides même si une autre version est bloquée par le contrôle UV.

## Mise à jour des extensions

Installer **blendup.zip** dans Blender pour mettre à jour l'extension (version interne 0.6.3). Pour Godot, utiliser **Paramètres → Mettre à jour le panneau Godot**, puis rouvrir le projet, ou installer **blendup-godot.zip** (plugin 0.2.0).

Les instances Godot placées avant cette mise à jour restent des instances ordinaires. Le sélecteur de variante concerne les nouveaux placements effectués depuis le panneau BlendUp.

## Téléchargements

- Windows : `BlendUp_0.2.0_x64-setup.exe`
- Linux : `BlendUp_0.2.0_amd64.deb` ou `BlendUp_0.2.0_amd64.AppImage`
- Extension Blender : `blendup.zip`
- Extension Godot : `blendup-godot.zip`

Les fichiers `SHA256SUMS-windows.txt` et `SHA256SUMS-linux.txt` publiés par le workflow permettent de vérifier les téléchargements. Les archives de code source ajoutées par GitHub correspondent au tag `v0.2.0`.
