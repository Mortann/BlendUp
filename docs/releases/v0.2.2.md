# BlendUp v0.2.2

Cette version respecte les collections exclues à l'export et conserve le contexte de travail lors des sauvegardes et des ouvertures dans Blender.

- Les exports GLB et FBX utilisent le View Layer actif, y compris pour les objets sélectionnés. Les collections exclues et leurs sous-collections restent hors de l'export ; les objets partagés avec une collection active restent exportables.
- Si un mesh dépend d'une armature exclue, un message indique quelle armature réactiver. Masquer un objet avec l'œil ne l'exclut pas de l'export.
- La sauvegarde, la préparation UV et l'export automatique préservent le mode Pose, le rig actif et la sélection, y compris après un échec d'export.
- Une session Blender avec BlendUp actif peut recevoir un fichier même si son fichier courant n'a jamais été enregistré ou appartient à un autre projet. Blender propose sa confirmation native **Enregistrer / Ne pas enregistrer / Annuler** avant de remplacer le travail non enregistré.
- Le clic droit **Ouvrir dans une nouvelle fenêtre** lance directement l'exécutable Blender, y compris pour une installation Steam.
- Une session qui ne répond pas produit un message dans BlendUp, sans lancer automatiquement une seconde session.

## Installation

- Application : **0.2.2**. Extension Blender : **0.6.5**, Blender 4.2 ou plus récent.
- Mettre à jour l'application et réinstaller `blendup.zip`, puis redémarrer Blender pour activer le nouveau pont entre les sessions.
- Le pont nécessite l'extension BlendUp active dans la session Blender à réutiliser.

## Validation

Les tests couvrent le View Layer, les sauvegardes en mode Pose avec exports GLB/FBX, la restauration après erreur, les clips et poses exportés, ainsi que l'installation du ZIP. Le pont est également testé dans une instance Blender interactive isolée pour les fichiers modifiés, sans nom, déjà ouverts et sans modification. L'interface Linux n'est pas testée localement sous Windows.
