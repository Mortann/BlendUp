# BlendUp v0.2.3

Les objets masqués dans Blender sont désormais exclus des exports GLB et FBX. Un high poly caché avec l'œil peut rester dans le même fichier que le low poly sans apparaître dans le jeu.

- Les exports respectent l'œil des objets et des collections, la désactivation dans le viewport et les exclusions du View Layer, y compris en mode « objets sélectionnés uniquement ».
- Les objets visibles restent exportables lorsqu'ils sont simplement non sélectionnables ou désactivés pour le rendu. Un objet partagé entre collections reste exportable s'il est visible via une collection active.
- Si un mesh visible nécessite une armature masquée, l'export indique laquelle réafficher, au lieu de produire un personnage sans squelette.
- Les meshes masqués ou exclus ne participent plus au contrôle UV. Les anciens rapports UV sont marqués obsolètes pour être renouvelés avec ce nouveau périmètre.
- L'export conserve la visibilité, la sélection et le mode de travail de Blender. La règle est partagée par l'addon et l'application desktop.

## Installation

Application : **0.2.3**. Extension Blender : **0.6.6**.

Mettre à jour l'application et réinstaller `blendup.zip`, puis redémarrer Blender. Pour l'export depuis l'application, enregistrer le `.blend` après avoir masqué les objets : BlendUp utilise la visibilité sauvegardée dans le fichier. Réexporter les anciens GLB/FBX pour retirer leur high poly.

## Validation

Tests Blender sur les objets et collections masqués, les objets partagés, les armatures requises, la restauration du contexte, les contenus GLB/FBX et la visibilité après sauvegarde et réouverture. Les contrôles UV vérifient qu'un high poly masqué avec des UV invalides ne bloque pas le low poly visible.
