# BlendUp v0.2.1

Cette version corrige l’export des personnages animés et ajoute leur lecture directement dans BlendUp. Elle inclut aussi les dernières améliorations de la version 0.2.0 présentes sur les branches de développement.

## Animations

- Les actions du rig sont exportées en clips distincts, avec leurs noms, leur cadence et leurs propres plages d’images.
- Les contraintes et propriétés des contrôleurs Rigify sont échantillonnées pour conserver les poses du personnage dans les exports GLB et FBX.
- Le metarig et les formes des contrôleurs sont exclus du personnage exporté ; les anciennes pistes NLA ne dupliquent plus les clips.
- L’onglet **3D / Animations** permet de choisir un clip, lire ou mettre en pause, déplacer la tête de lecture, changer la vitesse et activer la boucle.
- La pose de repos, l’affichage du squelette et le recentrage facilitent la vérification de l’export.
- En cas d’échec d’export, le précédent fichier reste disponible.

Les segments courbes des B-Bones restent soumis aux limites des formats GLB/FBX. Réexporter les personnages existants pour bénéficier des corrections.

## Extensions et installation

- **Windows** : `BlendUp_0.2.1_x64-setup.exe`.
- **Linux** : `BlendUp_0.2.1_amd64.deb` ou `BlendUp_0.2.1_amd64.AppImage`.
- **Blender** : réinstaller `blendup.zip` puis activer BlendUp dans les préférences. Version de l’add-on : **0.6.4**, Blender 4.2 ou plus récent.
- **Godot** : `blendup-godot.zip`, ou mise à jour depuis les paramètres de BlendUp.

Les fichiers `SHA256SUMS-windows.txt` et `SHA256SUMS-linux.txt` permettent de vérifier les téléchargements. Les archives de code source GitHub correspondent au commit du tag `v0.2.1`.
