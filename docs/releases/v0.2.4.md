# BlendUp v0.2.4

- BlendUp affiche sa version dans les paramètres et recherche les nouvelles versions au démarrage, puis toutes les six heures. Un bouton permet aussi de vérifier manuellement. L’installation reste à ton choix.
- Sous Windows, « Mettre à jour » télécharge l’exécutable officiel et vérifie son empreinte SHA-256 avant de lancer l’assistant. Un téléchargement échoué laisse BlendUp ouvert.
- Le nouvel exécutable `BlendUp_0.2.4_x64-update.exe` met à jour l’application, l’add-on Blender et les add-ons BlendUp des projets Godot choisis. Il conserve les réglages et sauvegarde les fichiers remplacés. Enregistre ton travail et ferme BlendUp, Blender et Godot avant une mise à jour lancée séparément.
- L’installateur habituel reste disponible pour une première installation. Sous Linux, BlendUp propose la page de téléchargement de la nouvelle version.

Cette version inclut les corrections de la série 0.2.3 : les objets masqués ou exclus dans le View Layer ne sont pas exportés, le mode Pose est restauré après sauvegarde et l’ouverture d’un asset réutilise Blender avec sa demande d’enregistrement. Le menu contextuel permet d’ouvrir une nouvelle fenêtre Blender sans passer par Steam.

Après installation, les prochaines versions publiées seront proposées automatiquement. Les projets Godot non connus de BlendUp peuvent être ajoutés à l’assistant de mise à jour.
