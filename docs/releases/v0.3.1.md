# BlendUp 0.3.1 — Outliner compact et affichage LOW / HIGH

- Une collection par pièce (`Epaulière1_Droite`) remplace les niveaux BAKE / LOW / HIGH / CAGE pour les nouvelles paires.
- Le bouton **Simplifier** dans **BlendUp → Assets dans la scène** convertit les anciennes structures à la demande, sans modifier leurs meshes ni leurs matériaux.
- **Assets / Détails** dans l’en-tête de l’Outliner permet d’afficher uniquement les collections ou de retrouver les objets.
- Une liste avec recherche et boutons **LOW / HIGH / Cage** permet de choisir la version à afficher et sélectionner.
- Les exports et contrôles UV conservent le LOW pendant l’affichage du HIGH, puis rétablissent la vue de travail.
- Extension Blender 0.7.1 incluse dans la mise à jour Windows.

Voir le [guide des textures et assets](https://github.com/Mortann/BlendUp/blob/master/docs/textures-et-bake.md).
