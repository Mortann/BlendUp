## Production

- `production/01-journal.md` : suivi des etapes de production.
- `production/02-installation-verification.md` : prerequis, installation locale et commandes de verification.

## Ligne directrice

BlendUp doit rester utile avant d'etre ambitieux. La V1 doit d'abord rendre le pipeline Blender -> Unity fiable, visible et agreable pour une petite equipe.

## Documentation Vivante

Ces documents doivent etre maintenus pendant la production. Toute decision importante, changement de scope, contrainte technique ou arbitrage produit doit etre reporte dans le document correspondant.
